# 🧠 心理学人体模型 · 北大347 复习版

一个在浏览器里用的 3D 大脑复习工具：真实解剖大脑模型（Z-Anatomy）+ 心理学知识卡 + 北大347 历年真题（2012–2026，182 题）。

## 怎么打开

**Windows**：双击 `双击启动.bat`，会弹出一个黑色窗口（本地服务器）并自动打开浏览器（电脑需装有 Python）。看完关掉黑色窗口即可。

**Mac / 其他**：在这个文件夹里打开终端，运行 `python3 serve.py`。

> 不能直接双击 `index.html` 打开——浏览器会拦截模型文件的加载。

**打开后还是旧版本？**（左上角没有「真题」按钮）

1. 把所有黑色命令行窗口都关掉——之前启动的旧服务器还开着的话，浏览器连的其实是旧文件夹。
2. 重新双击 `双击启动.bat`；如果黑色窗口提示端口被占用，说明还有旧窗口没关。
3. 在浏览器里按 `Ctrl + F5` 强制刷新一次。

## 三个选项卡

| 选项卡 | 内容 |
|---|---|
| 按结构 | 20 个重点脑区，每张卡有位置、功能、病变、实验、治疗，以及「🎯 考研考点关联」和「📝 真题考点」 |
| 按功能 | 27 个功能分组（视觉、记忆、思维决策、心理障碍的脑机制……），点一个功能相关脑区一起亮 |
| 真题 | 97 个考点按科目 → 章节排列，每个考点有核心要点 + 考过的全部真题；也能按年份刷题、搜关键词。带 🧠 的考点点开会在模型上高亮相关脑区 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `data.js` | 脑区知识卡、功能分组、考点关联 |
| `exam.js` | 真题考点库（要点 + 关联脑区） |
| `questions.js` | 历年真题（由 `../北大347历年真题题目（2026）.xlsx` 整理，已修正识别错字） |
| `atlas.js` | 其余约 130 个解剖结构的中文名和一句话简介 |
| `app.js` / `index.html` | 页面逻辑与样式 |
| `models/brain.glb` | 大脑 3D 模型 |

**加新一年的真题**：在 `questions.js` 里照格式加一行，`topics` 填 `exam.js` 里的考点 id；新考点就在 `exam.js` 的 `TOPICS` 里加一项。

## 自己的修改存在哪

在页面里编辑的内容（知识卡、功能分组、考点笔记）存在当前浏览器里，换浏览器或清缓存会丢。右上角「⬇ 导出」可以把全部修改存成 `我的修改.json` 备份，「⬆ 导入」恢复。
