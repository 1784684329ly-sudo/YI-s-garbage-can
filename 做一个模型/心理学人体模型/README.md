# 🧠 心理学人体模型 · 北大347 复习版

一个专门用来“看懂心理现象在大脑里怎么发生”的 3D 大脑：真实解剖模型（Z-Anatomy）+ 脑区卡 + 北大347 历年真题（2012–2026，182 题）的脑机制 + 各类心理障碍的病变机理。

## 怎么打开

**Windows**：双击 `双击启动.bat`，会弹出一个黑色窗口（本地服务器）并自动打开浏览器（电脑需装有 Python）。看完关掉黑色窗口即可。

**Mac / 其他**：在这个文件夹里打开终端，运行 `python3 serve.py`。

> 不能直接双击 `index.html` 打开——浏览器会拦截模型文件的加载。

**打开后还是旧版本？**（左上角没有「变态」按钮，或页面顶部出现红色提示）

1. 把所有黑色命令行窗口都关掉——之前启动的旧服务器还开着的话，浏览器连的其实是旧文件夹。
2. 重新双击 `双击启动.bat`；如果黑色窗口提示端口被占用，说明还有旧窗口没关。
3. 在浏览器里按 `Ctrl + Shift + R`（或按住 Ctrl 点刷新按钮）强制刷新一次。

## 四个选项卡

| 选项卡 | 内容 |
|---|---|
| 结构 | 20 个重点脑区。卡片底部列出相关疾病和涉及该脑区的真题 |
| 功能 | 31 个功能分组（视觉、痛觉、记忆、思维决策、应激与HPA轴、两半球……），含「神经递质系统」一类（突触与药物原理、多巴胺、5-HT、去甲肾上腺素、乙酰胆碱、GABA与谷氨酸）。点一个功能相关脑区一起亮，并列出相关真题和疾病 |
| 真题 | 按年份列出全部真题。点带 🧠 的题目，展开它在大脑里的机制，模型同时高亮相关脑区；统计、测量、管理等不涉及脑机制的题显示为灰色 |
| 变态 | 30 种心理障碍，每种分节写病变机理（递质、环路、内分泌、遗传）和治疗如何作用于大脑（药物在突触上的作用步骤、心理治疗的脑机制） |

模型上的**金色高亮**是更精细的部位（中脑VTA、尾状核、眶额、乳头体等），带标签。

## 文件说明

| 文件 | 作用 |
|---|---|
| `data.js` | 脑区卡、功能分组 |
| `questions.js` | 历年真题（由 `../北大347历年真题题目（2026）.xlsx` 整理，已修正识别错字），每题标注对应的脑机制 |
| `mechanisms.js` | 真题脑机制（每条讲一个心理现象在脑中如何发生，可被多道题共用） |
| `disorders.js` | 变态专栏：心理障碍的病变机理 |
| `atlas.js` | 其余约 130 个解剖结构的中文名和一句话简介 |
| `app.js` / `index.html` | 页面逻辑与样式 |
| `models/brain.glb` | 大脑 3D 模型 |

**加新一年的真题**：在 `questions.js` 里照格式加一行，`mech` 填 `mechanisms.js` 里的机制 id（问疾病的题用 `dis` 填 `disorders.js` 里的疾病 id；不涉及大脑就都不填）。

## 自己的修改存在哪

在页面里编辑的内容（脑区卡、功能分组）存在当前浏览器里，换浏览器或清缓存会丢。右上角「⬇ 导出」可以把全部修改存成 `我的修改.json` 备份，「⬆ 导入」恢复。
